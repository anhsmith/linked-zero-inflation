# Linked zero inflation in brms

R code for fitting the linked zero-inflated negative binomial model of Smith et al. ([2012](https://doi.org/10.1890/12-0460.1), [2014](https://doi.org/10.3354/meps10653)) in [brms](https://paul-buerkner.github.io/brms/), with the snapper data from Te Whanganui-A-Hei (Hahei) Marine Reserve as a worked example.

The vignette is at <https://anhsmith.github.io/linked-zero-inflation/>. To render it locally, run `quarto render` from the repository root (requires R, brms, cmdstanr, tidyverse, and tidybayes).
